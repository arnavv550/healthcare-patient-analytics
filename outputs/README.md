# Outputs

This folder contains generated analytical outputs from the Python workflow.

Expected outputs include:

- `analytical_sample.csv` — cleaned analytical sample
- `kpi_summary.csv` — key project metrics
- `readmission_by_age.csv` — readmission rates by age group
- `readmission_by_age.png` — readmission visualization
- `model_report.txt` — baseline model performance

These files are generated when `src/analysis.py` is executed.

Generated outputs may be updated as the analysis workflow evolves.
