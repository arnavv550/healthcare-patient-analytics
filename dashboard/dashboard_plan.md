# Healthcare Patient Analytics Dashboard

## Objective

Create an executive-style dashboard to communicate patient readmission patterns, utilization trends, and key analytical findings.

The dashboard is intended for portfolio demonstration and analytical communication.

## KPI Cards

The dashboard should display:

- Total hospital encounters
- 30-day readmission rate
- Average length of hospital stay
- Average number of medications

## Core Visualizations

### 1. Readmission Rate by Age Group

Compare 30-day readmission rates across patient age groups.

**Purpose:** Identify age segments with relatively higher readmission rates.

### 2. Readmission Rate by Length of Stay

Show how readmission rate varies with time spent in the hospital.

**Purpose:** Identify potential patterns between hospitalization duration and readmission.

### 3. Prior Healthcare Utilization

Analyze readmission rates against prior inpatient, emergency, and outpatient utilization.

**Purpose:** Understand whether previous healthcare utilization is associated with higher readmission rates.

### 4. Patient Utilization Segmentation

Create segments based on prior healthcare utilization:

- No prior utilization
- Low utilization
- Moderate utilization
- High utilization

**Purpose:** Compare patient segments and identify groups with higher readmission rates.

## Recommended Filters

The dashboard can include filters for:

- Age group
- Gender
- Admission type
- Length of stay
- Prior healthcare utilization

## Key Insight Section

Include a short "So What?" section summarizing:

1. Which patient segments show higher readmission rates?
2. Which utilization patterns are associated with readmission?
3. What patterns could be useful for further healthcare analytics?

## Tools

- Python
- Pandas
- SQL
- Power BI

## Dashboard Design

Keep the dashboard clean and executive-friendly.

Prioritize:

- Clear KPI cards
- Simple comparisons
- Consistent terminology
- Minimal visual clutter
- Insight-oriented commentary
